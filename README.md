# dsh-yu-weibo ｜ 刷微博（只读）

访客身份读公开内容：不登录、不写、不需要账号。

它的职责只有一件事——把微博上「人类怎么说话」带回来当原料。

---

## 它做什么

| 环节 | 具体做什么 |
|---|---|
| 读 | 走 `m.weibo.cn` 的公开接口，取推荐流、热门与评论 |
| 去重 | 读过的记在 `seen.json`，最多保留 5000 条，按时间裁剪 |
| 记 | 把值得的原句与判断写进 `voice.md` / `notes.md`，供人格蒸馏 |

**它不写。** 点赞、评论、转发、发博在代码里直接拒绝，不是靠提示词约束。

---

## 安装

```powershell
dsh plugin --profile desktop add github:Speraymer/dsh-yu-weibo
```

装完重启 DSH，设置里出现「刷微博」。**不需要登录，装完就能跑。**

---

## 第一次使用

1. 点「立刻跑一轮」，看这次的日报/归档。
2. 觉得素材够用就把「自动跑」打开。
3. 想多要几个源，把关键词填上。

## 运行机制

**取内容**：在本机开一个隐藏的 Edge 实例，以访客身份请求 `m.weibo.cn` 的公开接口，**只发 GET**；取完就关，不长期驻留浏览器。

**去重**：`seen.json` 存已读 ID，写入时保留最近 5000 条。重复内容不会再被当成新材料。

**额度与窗口**：按「每日上限 + 谷时窗口」控量，跟另外两个内容源同一套口径。

**写操作**：`readOnly` 在代码里是硬编码的；即使调用方想发博，也没有可走的路由。

---

## 边界与已知限制

- **只有读**。想要点赞评论转发，这个插件做不到——那需要微博开放平台服务，且风险自负。
- **访客身份看到的「推荐」偏热门**，不是你的关注流（访客没有关注关系）。
- **接口不是官方 SDK**，微博改版会让它失效；失败时日志带原始响应。
- **去重表有上限**：超过 5000 条后老 ID 会被挤掉，很久以前读过的内容可能再次出现。
- **默认不自动跑**：这是有意的，微博素材量大，先看清楚再开。

## 依赖与降级

- 需要本机有 Edge（Windows 自带）。
- 不依赖任何账号、不依赖 CLI、不依赖其他插件。
- 没有模型权限时只写原料、不做判断。
